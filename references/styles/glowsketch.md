# Glow Sketch — светящиеся пунктирные контуры на тёмном

## Обязательно
- Фон почти чёрный `#07060b` + редкие звёзды `stars(t)`.
- Все объекты — **пунктирные светящиеся контуры** `glowLine(точки, прогресс, цвет, 5–6)`: мягкое свечение + тонкая направляющая + точки-пунктир. Не сплошной неон.
- Основной цвет линий холодно-белый `#cfe6ff`; **золото `#ffc85a` только для главного** (то, о чём сцена) + тёплое пятно `warm(cx,cy,r,a)` за ним.
- Контуры прорисовываются по времени (прогресс 0→1), а не появляются.

## Приёмы
- Объект = несколько ломаных: силуэт, детали (полосы, окна, мачты), разной толщины (4–6). Толщина и плотность подчёркивают важное.
- Свет/луч: треугольник с радиальным градиентом золота от источника к прозрачному, вращается по `t`.
- Вода/воздух: 3–4 синусоиды пунктиром с убывающей яркостью, фаза сдвигается со временем.
- Момент-акцент: объект «зажигается» — меняет цвет на золото + `warm` пульсирует; расходящееся кольцо `polyC` с убывающей прозрачностью — только для реально важного события.

## Движение
Спокойное и элегантное: медленная прорисовка, дрейф, плавное покачивание. Ускорение — только в кульминации.

## Текст
Тонкий sans (FONT 500–700), светлый, одно ключевое слово золотом с мягким свечением.

## Ошибки
Залитые яркие поверхности, свечение на весь кадр, фиолетовое на чёрном (грязный контраст), гигантский декоративный шар, не относящийся к сюжету.

## Пример сюжета
Прорисовывается маяк, в фонаре загорается золотой свет, луч разворачивается и находит в темноте парусник — корабль вспыхивает золотом.

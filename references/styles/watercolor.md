# Watercolor — живая акварель на бумаге (p5.brush)

Книжная иллюстрация, которая пишется на глазах: мокрые заливки с неровным краем, пигментным ободком и зерном, карандаш и уголь, тёплая бумага. Рисуют настоящие кисти библиотеки **p5.brush 3** (MIT, без p5.js — отдельная сборка `brush.js`).

Готовый пример: `assets/examples/watercolor_demo.html` (закат над горами → полёт птицы → ветка сакуры). Открой его перед работой и бери оттуда приёмы.

## Подключение (обязательно)
- В `<head>` раскомментируй строку `p5.brush@3.0.0/dist/brush.js`. three.js не нужен.
- Все помощники уже в шаблоне (раздел «акварель»): `paint`, `paintSprite`, `makePaper`, `layer`, `sprite`, `wetReveal`, `wipeReveal`, `pathReveal`, `boil`, `inkText`.

## Главное правило: кисти — только в SETUP
Акварельная заливка считается сотни миллисекунд, поэтому **в draw кисти не вызывать**. Схема:
1. `async function SETUP(){...}` — всё рисуешь кистями один раз и сохраняешь слои в объект `L`:
   `L.sky = paint(b => { ... }, seed)` — слой на весь кадр; `L.bird = paintSprite(b => {...}, 560, 460, seed)` — спрайт, рисуй вокруг (0,0).
2. В `draw(t)` — только композиция: `x.drawImage(L.paper,0,0)` первой строкой, затем слои, проявления, сдвиги.
Слои нарисованы **на белом** и кладутся умножением (multiply) — так краска ложится на бумагу как настоящая и слои просвечивают друг через друга. Не меняй это на обычное наложение.
Каждой `paint` давай свой seed — от него зависит рисунок, кадры одинаковы при каждом запуске.

## Кисти p5.brush (внутри paint, `b` = brush)
- Заливка-акварель: `b.noStroke(); b.fillBleed(.25,'out'); b.fillTexture(.5,.45); b.fill('#4f6182',170); b.polygon([[x,y],...])` / `b.rect(x,y,w,h)` / `b.circle(cx,cy,r,.4)` (последнее — неровность края).
  - `fill(цвет, 0–255)`: 110–200 для заливок; акварель прозрачна, тёмное = два слоя подряд.
  - `fillBleed(0–1,'out'|'in')`: растекание. Для больших фигур, которые ложатся друг на друга (горы, холмы), бери `'in'`, иначе край может обрезаться ровной линией.
  - `fillTexture(зерно, ободок)`: 0,3–0,6 и 0,3–0,6.
- Линия: `b.set('2B'|'HB'|'2H'|'cpencil'|'pen'|'rotring'|'charcoal'|'marker'|'marker2'|'spray', цвет, толщина 1–3)`, потом `b.line(...)`, `b.spline([[x,y,нажим],...], .5)`, `b.circle`, `b.rect`.
  Уголь `charcoal` для веток и стволов, `2B`/`HB` для эскизных штрихов, `pen` для мелких деталей (клюв, глаз).
- Штриховка: `b.hatch(12, 45, {rand:.1})` перед фигурой, потом `b.noHatch()`.
- Кисти уже масштабированы под 1080 px (`scaleBrushes(5)`). Для 16:9 1920×1080 тоже подходит.
- Большие фигуры заводи за края (−80…W+80), иначе на сдвиге видны края слоя.

## Как оживлять (в draw)
- **Проявление заливкой**: `wipeReveal(L.sky, prog(t,0,.8), 'down'|'up'|'left'|'right', seed)` — мокрый неровный край проходит через кадр.
- **Пятно растекается**: `wetReveal(L.sun, prog(t,.1,1), cx, cy, радиус, seed)` — для солнца, цветов, облаков, капель.
- **Мазок по пути**: `pathReveal(L.branch, точки, prog(t,.4,1.6), ширина)` — ветка, река, дорога, подпись-росчерк пишутся по линии. Точки те же, что ты передавал в `b.spline`.
- **Параллакс**: `layer(L.far, -t*3, 0, 1, 1.1)` — дальний слой медленно, ближний быстрее (до −10 px/с). Масштаб 1,1 нужен, чтобы при сдвиге не показался край слоя.
- **«Кипение»**: `const [a,c]=boil(t,1.2,seed)` и прибавляй `a,c` к сдвигу слоёв — рисунок чуть дрожит 8 раз в секунду, как покадровая рисованная анимация. Только 1–2 px.
- **Персонаж или предмет**: 2–3 позы спрайтом (`paintSprite` для каждой) и смена поз по времени: `L.bird[[0,1,2,1][Math.floor(t*10)%4]]` — взмах крыльев, шаг, моргание. Движение по пути — линейное по `t`, не `prog` (иначе в середине рывок).
- Стая или фон: тот же спрайт мелко (масштаб 0,15–0,25), полупрозрачно.

## Палитра
Бумага `#f3ead8`. Небо `#8fa9c9`, закат `#f2c28e` `#e39a74`, акцент `#a8242c` (солнце, ягоды). Горы: дальние `#8593b3`, средние `#4f6182`, ближние `#26334a`. Зелень `#7f9a6a` `#dfe6d2`, цветы `#eaa3b8` `#b33a5e`, дерево и уголь `#3b2a22`, тушь `#1b2436`.
На кадр 3–5 цветов. Светлое не рисуется — светлое это незакрашенная бумага.

## Текст
`inkText(s, cx, cy, размер, цвет, прозрачность)` — Lora курсивом, без подложек. На тёмной краске пиши светлым `#f6efe0`, на бумаге — тёмным `#22293a` или `#5a2a3a`. Заголовок 90–110 px, подпись 60–70 px, ставь в y 1450–1550.

## Движение и ритм
Спокойное: камера стоит или медленно дрейфует, сцены 3,5–5 с. Слой проявляется за 0,8–1,2 с, следующий начинается до конца предыдущего. Переход между сценами `'cut'` (если пейзаж продолжается) или `'fade'`. Вспышка `'flash'` в этом стиле не подходит.

## Ошибки
- Кисти в draw → тормоза и разные кадры. Только SETUP.
- Ровные векторные фигуры поверх акварели (обычные `x.fillRect` / `x.arc`) — выбиваются из стиля. Любая форма рисуется кистью.
- Обычное наложение слоёв вместо multiply — вокруг фигур белые прямоугольники.
- Пустой первый кадр: начинай проявление неба и главного пятна с t=0, к 1 с уже есть картинка.
- Тёмный текст на тёмных горах. Слишком насыщенные «цифровые» цвета: акварель приглушённая.

## Проверка
`node scripts/preview-edge.mjs --html ролик.html --out ./out` (Edge/Chrome без Playwright, Node 22+). SETUP с кистями идёт 15–30 с — это нормально. Скрипт пишет время одного кадра: если больше 33 мс, облегчи draw. `--frames 120,195` — нужные кадры, `--mp4` — готовый MP4.

## Пример сюжета
Бумага → сверху растекается небо, в центре расцветает красное солнце → слева направо, справа налево и снизу проявляются три гряды гор → «Акварель кодом». Дальше горы медленно плывут, стая вдали, через кадр пролетает птица, машет крыльями. Финал: зелёное пятно, по пути проводится угольная ветка, на ней по очереди распускаются цветы, «весна».

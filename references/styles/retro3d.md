# Retro 3D — лоу-поли графика игр начала 2000-х

## Обязательно
- three.js (раскомментируй строку в `<head>`). Рендер в **низком разрешении с пикселизацией**: `gl3d(scene, cam, 360, 640, true)`.
- Низкополигональные модели: конусы/цилиндры с 5–8 сегментами, боксы. Материал `MeshLambertMaterial({color, flatShading:true})` — гранёный свет.
- Туман `scene.fog = new THREE.Fog(цвет, 14, 90)` — дальние объекты растворяются, как на приставке.
- Поверх — сканлайны: каждые 6 px полоса `rgba(0,0,0,.16)` высотой 3 px.
- Игровой HUD: крупные моноширинные/пиксельные цифры с жёсткой чёрной тенью (смещение 5 px).

## Палитра
Насыщенная, «приставочная»: ночь `#1b0f33`, туман `#3a1d5c`, неон-розовый `#ff4fd8`, жёлтый HUD `#ffe14d`, красная машина `#e0303a`, синяя `#2f6bff`.

## Приёмы
- Бесконечная дорога: камера стоит, мир едет навстречу — z-позиция = `((i*шаг + скорость*t) % длина) - смещение` для разметки, деревьев, фонарей.
- Машина = корпус-бокс + кабина + спойлер + 4 колеса-цилиндра (8 сегментов) + стоп-огни `MeshBasicMaterial` (светятся без света).
- Горы — большие конусы с 5 гранями вдали, `fog:false` у материала, чтобы силуэт читался.
- Свет: `HemisphereLight` (небо/земля) + один `DirectionalLight`.
- Событие: обгон, прыжок, финиш; HUD реагирует (POS 2/8 → 1/8, мигает «ОБГОН!»).

## Движение
Камера «из-за спины» с лёгкой инерцией, машина виляет (`sin(t*1.8)`), колёса крутятся. Динамично.

## Ошибки
Гладкие высокополигональные модели, сглаженный рендер в полном разрешении, PBR-блеск — это уже CGI, а не Retro 3D.

## Пример сюжета
Ночная гонка: красная машина несётся по неоновой трассе среди гранёных ёлок, догоняет синего соперника и обгоняет — HUD переключается на «POS 1/8».

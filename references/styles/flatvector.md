# Flat Vector — плоская иллюстрация / инфографика

## Обязательно
- Только плоские заливки: без обводок, без градиентов внутри объектов, без текстур. Объём — максимум одной тенью-фигурой более тёмного тона.
- Простые геометрические формы: прямоугольники со скруглением (`rr`), круги, треугольники.
- Яркая, но согласованная палитра 6–8 цветов, светлый фон.
- Чёткая читаемая история: объект движется по понятной траектории к цели, результат подтверждается иконкой (галочка, сердечко, стрелка роста).

## Палитра-старт
Небо `#bfe6ff`, солнце `#ffd166`, здания `#219ebc #126782 #023047 #2a9d8f #ffb703 #fb8500`, дальний план `#9fd3ef`, трава `#8bd17c`, дорога `#3d405b`, акцент `#e76f51`, тёмный `#264653`.

## Приёмы
- Город: дальний ряд бледных прямоугольников + передний ряд цветных с сеткой окон (окна белые полупрозрачные, часть пропущена по `hj`).
- Облака: 3–4 белых круга, дрейфуют по x.
- Траектория: `bez(...)` + пунктир пройденного пути (`setLineDash([14,14])`, белый).
- Транспорт/дрон: корпус `rr`, винты — эллипсы с шириной `|cos(t*55)|` (иллюзия вращения), лёгкий наклон по направлению движения.
- Падение/отскок: `y = y0 + g·dt²/2`, на земле `sin` с затуханием `exp(-k·t)`.
- Иконка-результат «выпрыгивает» через `eBack`: круг-пин + белая галочка толстой линией.

## Движение
Чистое, дружелюбное, с перелётом (`eBack`) на появлениях. Всё в кадре слегка живое: облака, дым, вращение.

## Текст
FONT 700–800, тёмный `#264653` на светлом или белый на цветной плашке. Цифры инфографики — крупно.

## Ошибки
Обводки (это уже комикс), градиенты и блики (это уже 3D), слишком много мелких деталей.

## Пример сюжета
Дрон с посылкой летит над городом по пунктирной траектории, зависает над домиком, сбрасывает коробку на крыльцо — она подпрыгивает, над домом выскакивает зелёная галочка.

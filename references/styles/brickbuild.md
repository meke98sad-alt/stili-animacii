# Brick Build — мир из пластиковых кубиков

## Обязательно
- three.js (раскомментируй строку в `<head>`). `gl3d(scene, cam, 720, 1280)`.
- Всё собрано из **кирпичиков**: брусок `roundedBox(nx*U-.03, h, nz*U-.03, .035)` + штырьки-цилиндры сверху (r .24, h .18, 20+ сегментов) на сетке шага `U=.8`; высота кирпича `.96`, пластины `.32`.
- Пластик: `MeshStandardMaterial({color, roughness:.25, metalness:0})`, чистые насыщенные цвета.
- Зелёная базовая пластина со штырьками (`InstancedMesh` для 100–200 штырьков).
- Кирпичики **падают сверху и защёлкиваются** по очереди: `y = база + 6·(1−p)²`, после приземления короткий подскок `.16·sin`, при падении лёгкий поворот по y, который гаснет.
- Без минифигурок и логотипа на штырьках.

## Цвета
Красный `#d62d20`, белый `#f2f2f2`, жёлтый `#ffcd00`, синий `#0057a8` / `#0a3d7a`, зелёный `#2e9e46` / `#3aa655`, коричневый `#7b4a24`, прозрачно-голубой `#7fd3ff` (opacity .75) для окон. Небо `#9fd8ff`.

## Приёмы
- Стены «вперевязку»: чётные ряды — длинные кирпичи спереди/сзади, нечётные — по бокам.
- Крыша ступенями: пластина 6×6 → кирпич 6×4 → 6×2.
- Деревце: 2 коричневых 1×1 + 2 зелёных 2×2 + 1×1 сверху. Ставь деревья **за** домом или сбоку от камеры, а не перед ним.
- Свет: `HemisphereLight` + `DirectionalLight` с тенями (shadow camera ±9).
- Камера: облёт 3/4 сверху, радиус 18–21, высота 12–13, смотреть в центр постройки; вся постройка в кадре.

## Движение
Ритм сборки: новый кирпич каждые ~0,1 с, падение 0,3 с. Медленный облёт камеры всё время.

## Ошибки
Кирпичи без штырьков, матовые блёклые цвета, камера слишком близко (постройка режется), всё появляется сразу.

## Пример сюжета
На зелёной пластине из падающих кубиков за 3 секунды собирается домик: красно-белые стены, голубое окно, синяя ступенчатая крыша, рядом вырастает дерево и жёлтый цветок.

# CGI Motion — рекламный 3D-пэкшот

## Обязательно
- three.js (раскомментируй строку в `<head>`). `gl3d(scene, cam, 720, 1280)` — сглаженный рендер.
- Глянцевые материалы: `MeshPhysicalMaterial({color, roughness:.05–.2, clearcoat:1})`, металл `metalness:1, roughness:.15–.25`. Тени включены (`castShadow/receiveShadow`).
- **Студийный свет**: тёплый ключевой `SpotLight` сверху-сбоку (он едет по сцене → по объекту скользит блик) + 2 цветных контровых `PointLight` сзади (холодный и тёплый) — дают контур.
- Тёмный фон `#0b0809`, подиум (цилиндр с тонким золотым кольцом-тором по краю), полированный пол (`roughness .2, metalness .3`).
- Медленный облёт камеры (угол меняется на 0,6–1 рад за сцену) + плавный наезд.
- Частицы: `THREE.Points` с золотой пылью (`AdditiveBlending`, size .03–.04), медленно поднимаются.

## Приёмы
- Продукт из примитивов: `roundedBox` (флакон, коробка, телефон), цилиндры (крышка, горлышко), торы (кольца), сферы. Этикетка — плоскость с `CanvasTexture` (нарисуй на 2D-холсте название и строку мелким капслоком). Название — **выдуманное**, без реальных брендов и логотипов.
- Камера: `cam.position.set(sin(a)*r, h, cos(a)*r); cam.lookAt(0, центр_объекта, 0)`, r подобрать так, чтобы объект занимал ~55–65% ширины и не резался сверху.
- Без окружения (environment) в r128 отражения слабые — компенсируй ярким ключом (intensity 2–3) и контровыми.

## Палитра
Чёрный, золото `#e0b04a`, янтарь `#c97a1c`, кремовая этикетка `#f3e6cc`, контровые `#7fb2ff` / `#ffb070`.

## Ошибки
Плоский свет без бликов, объект обрезан сверху/снизу, мультяшные пропорции (это уже Clay Explainer), реальные логотипы.

## Пример сюжета
Янтарный флакон духов с золотой крышкой на чёрном подиуме: камера медленно облетает, по стеклу скользит блик, вокруг поднимается золотая пыль.

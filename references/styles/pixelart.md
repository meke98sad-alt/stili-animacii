# Pixel Art — ретро-игра 8/16 бит

## Обязательно
- Рисуй в маленький холст и увеличивай без сглаживания: `const P=makePixel(180,320)` (один раз, вне draw), в draw — `P.px(x,y,w,h,цвет)` целыми координатами, в конце `P.blit()`. Масштаб 6× → один «пиксель» = 6 px.
- Ограниченная палитра: 8–16 цветов на ролик. Никаких градиентов — только полосы цветов с **дизерингом** на стыках (шахматка 1×1 из двух соседних цветов).
- Движение ступенчатое, как в старых играх: время для анимации спрайтов `const fr=Math.floor(t*12)` (12 к/с), позиции объектов можно двигать плавно, но округлять.
- Тени и свет — отдельными цветами палитры, не прозрачностью.

## Палитра-старт (закат)
`#24163f #35195a #55206a #7f2a70 #b23c6c #de5d5e #f58b56 #fbb767` — небо; `#1a0f2c` — силуэты; `#2a1a4c / #46307a` — вода; акценты `#ffd27a`, `#d8323c`, `#5cc8ff`, `#f4f4f4`.
Ночь/подземелье/лес — придумай свои 8–12 цветов в том же духе.

## Приёмы
- Небо полосами по 20–24 px низкого разрешения, на каждом стыке строка дизеринга.
- Солнце/луна — круг построчно (`w=√(R²−y²)`), «ретро-разрезы» — пропуск каждой 5-й строки в нижней половине.
- Силуэты зданий: массив прямоугольников со случайной высотой (`rng(seed)`), окна — одиночные жёлтые пиксели, мигают по `fr`.
- Вода: тёмная заливка + короткие светлые штрихи, ползущие по `fr`; отражение солнца — горизонтальные полоски убывающей ширины.
- Спрайт персонажа/транспорта 16–32 px: собирай из `P.px` построчно; 2–4 кадра анимации по `fr%4`.
- Частицы: одиночные пиксели (искры, брызги, звёзды) с мерцанием `(fr+i)%7>1`.

## Движение
Камера статична или сдвигается шагами по 1 «пикселю». Объекты: проход персонажа/транспорта через кадр, прыжок по параболе, подбор монетки (+1 всплывает вверх).

## Текст
Надписи на латинице — `"Press Start 2P"` 28–48 px; по-русски — FONT 800, с жёсткой тенью смещением 5 px без размытия (как в игре). Можно игровой HUD: счёт, жизни-сердечки из пикселей.

## Ошибки
Сглаженные края, полупрозрачность, градиенты, тонкие линии в 1 px экранного разрешения, слишком много цветов.

## Пример сюжета
Катер проплывает по вечерней реке мимо силуэтов купола и шпиля, за ним пенный след, над водой машут крыльями чайки.

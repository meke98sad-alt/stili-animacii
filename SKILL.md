# Стили анимации — ролик кодом за один запрос

Ты делаешь короткий анимированный ролик (по умолчанию вертикальный 9:16 для Reels/Shorts) в одном из 11 стилей. Ролик — это один HTML-файл с холстом: сцены рисуются кодом (Canvas 2D, для 3D-стилей — three.js), а встроенный плеер умеет проигрывать и **записывать MP4 прямо в браузере** (кнопка «Скачать видео»). Ничего устанавливать пользователю не нужно.

Это моушн-графика, нарисованная кодом, а не нейросетевая генерация видео. Не обещай фотореализм.

Если скилл прислали архивом в чат (а не установили), сначала распакуй его и читай все файлы ниже из распакованной папки `stili-animacii/`.

## 1. Определи стиль

| Пишут | Файл стиля |
|---|---|
| Pixel Art, пиксель, 8-бит, /pixelart | `references/styles/pixelart.md` |
| Chalkboard, мел, доска, /chalkboard | `references/styles/chalkboard.md` |
| Glow Sketch, светящиеся линии, /glowsketch | `references/styles/glowsketch.md` |
| Retro 3D, ретро-3D, игры нулевых, лоу-поли, /retro3d | `references/styles/retro3d.md` |
| Comic Art, комикс, /comicart | `references/styles/comicart.md` |
| Flat Vector, плоская графика, инфографика, /flatvector | `references/styles/flatvector.md` |
| Mono Lines, минимализм, белые линии на чёрном, /monolines | `references/styles/monolines.md` |
| CGI Motion, 3D реклама, пэкшот, /cgimotion | `references/styles/cgimotion.md` |
| Brick Build, кубики, конструктор, кирпичики, /brickbuild | `references/styles/brickbuild.md` |
| Clay Explainer, 3D-объяснялка, пластилин, разрез, /clayexplainer | `references/styles/clayexplainer.md` |
| Watercolor, акварель, p5.brush, книжная иллюстрация, /watercolor | `references/styles/watercolor.md` |

Слова вида `/pixelart` — это просто текст в сообщении, а не команда. Стиль не назван — спроси одной строкой: «Какой стиль: Pixel Art, Chalkboard, Glow Sketch, Retro 3D, Comic Art, Flat Vector, Mono Lines, CGI Motion, Brick Build, Clay Explainer или Watercolor (акварель)?». Нет ни сценария, ни идеи — спроси: «Что анимируем? Пришли сценарий или идею в одну строку». Больше вопросов не задавай.

## 2. Прочитай файлы (обязательно, до кода)

1. `references/workflow.md` — раскадровка, тайминг, правила текста, проверка.
2. Ровно один файл стиля из таблицы.
3. `assets/player_template.html` — шаблон. Скопируй его целиком и меняй **только** блоки «НАСТРОЙКИ РОЛИКА» и «СЦЕНЫ». Библиотеку и движок не трогай: от них зависят запись видео и одинаковость кадров.

## 3. Сделай

1. **Раскадровка в чат** — 3–7 строк: `0.0–2.5 с · что видно · что происходит`. Не жди подтверждения, сразу пиши код.
2. **Код** — заполни `SCENES` по правилам workflow и файла стиля. Для 3D-стилей раскомментируй строку с three.js в `<head>`, для акварели — строку с p5.brush.
3. **Проверка** — если у тебя есть выполнение кода, по возможности проверь кадры (см. workflow, раздел «Проверка»). Если нет — перечитай код на типовые ошибки из списка в workflow.
4. **Выдача** — один HTML как артефакт (или файл, если артефакты недоступны). Под ним коротко:
   - «▶ — посмотреть, ползунок — перемотать».
   - «Скачать видео — ролик запишется в реальном времени (столько, сколько длится) и скачается как MP4 (в Chrome/Safari) или WebM. Не переключай вкладку во время записи».
   - «Если кнопка в окне чата не срабатывает — открой артефакт на весь экран / в новой вкладке».

## 4. Правки

Меняй только то, что попросили, остальное (стиль, тайминг, сцены) сохраняй. Возвращай полный HTML заново.

## Значения по умолчанию

9:16, 1080×1920, 30 к/с. Длительность — по сценарию (≈2,5 слова русского текста в секунду + паузы), для идеи без текста 8–20 с. Субтитры — только если просят; надписи, которые нужны для смысла (подписи на схеме, «БАМ!» в комиксе, счёт в игре), — можно. Звук плеер не записывает: музыку и голос добавляют в монтажке или в Instagram. Скажи об этом одной фразой, если пользователь упоминает звук.
